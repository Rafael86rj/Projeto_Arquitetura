# ARQ Escolha

Projeto didático criado somente com HTML, CSS e JavaScript puro.

## Como executar

1. Abra esta pasta no VS Code.
2. Instale a extensão Live Server.
3. Clique com o botão direito em `index.html`.
4. Selecione **Open with Live Server**.

Não é necessário instalar Node.js, bibliotecas ou dependências.

## Organização

- `index.html`: capa do site.
- `simulador.html`: formulário e área de resultado.
- `css/style.css`: identidade visual e responsividade.
- `js/simulador.js`: dados, validação e regras de cálculo.
- `assets/`: imagem utilizada na capa.
- `GUIA-DE-ESTUDO.md`: mapa didático das linguagens e principais recursos.

## Publicar no GitHub Pages

Envie toda a pasta para um repositório. No GitHub, abra **Settings > Pages**,
selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/root`.

## Importante

Os dados e cálculos atuais são demonstrativos. Substitua o array `solucoes`
e as condições em `calcularSolucao()` somente depois de mapear as regras reais.
